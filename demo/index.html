    Before anyone trusts a new system, it has to agree with the old one. A back-test runs both on the same data and compares every job.

    Step 1 · Same mistakes in, same numbers out

    First the app’s calculations are run with all the workbook’s mistakes deliberately left in. If the two agree exactly, the app understands the workbook’s logic.
